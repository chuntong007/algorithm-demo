# Algorithm Demo

一个用于学习和练习 JavaScript 数据结构与算法的综合项目。

## 🎯 项目目的

该项目旨在通过代码实现各种常见的数据结构和经典算法，帮助开发者深入理解计算机科学的基础知识，提升编程能力。

## 📦 项目内容

### 数据结构 (Data Structures)
- [ ] 数组 (Array)
- [ ] 链表 (Linked List)
- [ ] 栈 (Stack)
- [ ] 队列 (Queue)
- [ ] 树 (Tree)
  - 二叉树 (Binary Tree)
  - 二叉搜索树 (Binary Search Tree)
  - 平衡二叉树 (AVL Tree)
  - 红黑树 (Red-Black Tree)
- [ ] 堆 (Heap)
- [ ] 图 (Graph)
- [ ] 哈希表 (Hash Table)
- [ ] 字典树 (Trie)

### 排序算法 (Sorting)
- [ ] 冒泡排序 (Bubble Sort)
- [ ] 选择排序 (Selection Sort)
- [ ] 插入排序 (Insertion Sort)
- [ ] 归并排序 (Merge Sort)
- [ ] 快速排序 (Quick Sort)
- [ ] 堆排序 (Heap Sort)
- [ ] 计数排序 (Counting Sort)

## 📂 项目结构

```
algorithm-demo/
├── src/
│   ├── dataStructures/          # 数据结构实现
│   ├── sorting/                 # 排序算法
│   ├── searching/               # 搜索算法
│   ├── dynamicProgramming/      # 动态规划
│   └── utils/                   # 工具函数
├── tests/                       # 单元测试
├── README.md                    # 项目说明
└── package.json                 # 项目配置
```

## 🚀 快速开始

### 环境要求
- Node.js >= 12.0
- npm >= 6.0

### 安装依赖
```bash
npm install
```

### 运行测试
```bash
npm test
```

### 开发
```bash
npm run dev
```
